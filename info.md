# Morning Routine

Visual morning routine for Home Assistant — designed for kids who can't read a clock yet. Each step pops up full-screen with a big image and a green→red countdown bar. Image and bar share the same color so the urgency is obvious at a glance.

- Fully visual — no time-reading needed
- Configurable via UI (no YAML)
- DE / LB / EN
- Optional TTS announcements (Lux-TTS friendly)
- Auto-closes back to your dashboard when the routine is done
- Single-install: card is bundled with the integration
